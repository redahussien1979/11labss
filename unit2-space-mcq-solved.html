Grammar: The Second Conditional

Questions 45–62
45

We use the second conditional to talk about:

Book
  • Asomething that always happens, like a scientific fact
  • Bsomething we imagine, which is not real now
  • Csomething that happened and finished in the past
  • Dan instruction or an order
Correct answer: BThe second conditional talks about something we imagine in the present or the future, but which is not real.
46

Which is the correct structure of the second conditional?

Book
  • AIf + present simple, will + infinitive
  • BIf + will, would + -ing
  • CIf + past simple, would + bare infinitive
  • DIf + would, past simple
Correct answer: CThe pattern is: If + past simple, would + bare infinitive, e.g. If I went to space, I would take a camera.
47

If I ______ to space, I would take my camera.

Book
  • Ago
  • Bwill go
  • Cwould go
  • Dwent
Correct answer: DAfter if in the second conditional we use the past simple: went.
48

If Omar had a plane, he ______ to many countries.

Book
  • Awill travel
  • Bwould travel
  • Ctravels
  • Dtravelled
Correct answer: BThe result clause uses would + bare infinitive: would travel.
49

If I ______ an astronaut, I would go to Mars.

★ Extra
  • Aam
  • Bwere
  • Cwill be
  • Dwould be
Correct answer: BIn the second conditional we use the past form of be, and were is used for all persons: If I were an astronaut …
50

She would grow vegetables if she ______ on the space station.

★ Extra
  • Alives
  • Bwill live
  • Clived
  • Dwould live
Correct answer: CThe if clause takes the past simple, even when it comes second in the sentence: if she lived.
51

Which sentence is grammatically CORRECT?

★ Extra
  • AIf I would have a rocket, I would fly to the Moon.
  • BIf I had a rocket, I will fly to the Moon.
  • CIf I had a rocket, I would fly to the Moon.
  • DIf I have a rocket, I would flew to the Moon.
Correct answer: COnly C follows the rule If + past simple, would + bare infinitive. We never use would directly after if in this structure.
52

Book
  • Awouldn't
  • Bdidn't would
  • Cnot would
  • Dwon't would
Correct answer: AA negative second conditional result uses wouldn't + bare infinitive.
53

If we ______ enough water, the corn wouldn't grow well.

★ Extra
  • Adon't have
  • Bdidn't have
  • Cwouldn't have
  • Dhaven't
Correct answer: BThe if clause needs a negative past simple: didn't have.
54

______ you go to Mars if you had the chance?

Book
  • AWill
  • BDo
  • CDid
  • DWould
Correct answer: DTo make a second conditional question we start with Would + subject + bare infinitive.

Where ______ you go if you had a rocket?

Book
  • Awill
  • Bwould
  • Cdo
  • Ddid
Correct answer: BAfter the question word we use would: Where would you go …?

If NASA sent out more Voyagers, they ______ many years to travel to the edge of the solar system.

If I ______ one million dirhams, I would take all my friends and family on a nice vacation.

  • Cwould have

59

Look at these two sentences:
(1) "If I go to space, I will be happy." (2) "If I went to space, I would be happy."
Which answer describes them correctly?

Book
  • A(1) is the first conditional and (2) is the second conditional.
  • B(1) is the second conditional and (2) is the first conditional.
  • CBoth are second conditional sentences.
  • DBoth are first conditional sentences.
Correct answer: ASentence (1) uses present simple + will (first conditional, a real possibility). Sentence (2) uses past simple + would (second conditional, imagined).
